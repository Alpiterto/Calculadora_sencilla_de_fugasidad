Calculadora de Fugacidad de Gases (GUI)Una aplicación de escritorio desarrollada en Python que calcula los coeficientes de fugacidad ($\phi_i$) y las fugacidades parciales ($f_i$) de una mezcla ternaria (Metano, Propileno y Agua).Características:Implementación de la Ecuación de Estado Virial (truncada en el segundo coeficiente).Cálculo de reglas de mezcla para $T_c$, $P_c$, y $\omega$ (Pitzer-Curl / Tsonopoulos).Interfaz moderna y fácil de usar construida con CustomTkinter.Validación automática de fracciones molares ($\sum y_i = 1$).
Gas Fugacity Calculator (GUI)A Python desktop application designed to calculate fugacity coefficients ($\phi_i$) and partial fugacities ($f_i$) for a ternary gas mixture (Methane, Propylene, and Water).Features:Implementation of the Virial Equation of State (truncated at the second coefficient).Calculation of mixing rules for $T_c$, $P_c$, and $\omega$ (Pitzer-Curl / Tsonopoulos).Modern, user-friendly interface built with CustomTkinter.Automatic validation of molar fractions ($\sum y_i = 1$).
